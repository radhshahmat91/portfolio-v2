# Radh Shahmat — Ultra Portfolio

A redesigned, animation-heavy portfolio built as a dependency-free static site.

## Files
- `index.html` — content and structure
- `styles.css` — visual system, responsive layout and animations
- `script.js` — loader, particles, custom cursor, reveal animations, magnetic buttons, tilt cards and interactions

## Run locally
Just open `index.html` in a browser.

For a local server:
```bash
python -m http.server 5500
```
Then open `http://localhost:5500`.

## GitHub Pages
Upload the contents of this folder to your portfolio repository and enable GitHub Pages from the branch/root directory.

## Notes
- Project/live/GitHub URLs are preserved from the current portfolio.
- The profile photo is loaded from the current GitHub Pages portfolio URL.
- Project cover images use Unsplash URLs.
- The site is intentionally vanilla HTML/CSS/JS so it remains easy to deploy on GitHub Pages with no build step.
- `Radh_Shahmat_CV.pdf` can be dropped into the root folder to activate the local CV link.
